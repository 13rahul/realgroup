# Real Chakki Fresh Atta

Static marketing website for **Real Chakki Fresh Atta** (Real Group / RealMulti Grain Mill Pvt. Ltd., Baramati).

## Live locally

Open with any static server, e.g. XAMPP:

`http://localhost/RealGroup/`

Or:

```bash
python -m http.server 8080
```

Then visit `http://127.0.0.1:8080/`

## Deploy on Hostinger

1. In Hostinger hPanel → **Websites** → your domain → **File Manager** or **Git**.
2. Upload this repo (or connect GitHub and pull `main`).
3. Point the domain document root to the folder that contains `index.html`.
4. No build step — HTML/CSS/JS only.
